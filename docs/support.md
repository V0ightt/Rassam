# 1.0 support envelope

- Public GitHub.com repositories, and local folders in Chromium browsers (File System Access API)
- Import analysis for TypeScript/JavaScript, Python, Go, Java/Kotlin, Rust, C/C++ and Ruby; structural coverage for other languages
- Full authoring at 1024x768 or larger
- Latest two stable desktop releases of Chrome, Edge, Firefox, and Safari (local folders need Chrome or Edge)
- Repository trees up to 100,000 entries
- Automatic analysis up to 10,000 relevant text files and 25 MiB of source for GitHub repositories
- Local folders up to 20,000 files after ignore rules

Private repositories on the hosted profile, GitHub Enterprise, accounts, cloud sync, full mobile authoring, code execution, and source-code mutation are not supported in 1.0.
