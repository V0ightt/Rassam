# 1.0 support envelope

- Public GitHub.com repositories only
- JavaScript, TypeScript, JSX, TSX, and Next.js semantic analysis
- Structural path analysis for other languages
- Full graph authoring at 1024x768 or larger
- Latest two stable desktop releases of Chrome, Edge, Firefox, and Safari
- Repository trees up to 100,000 entries
- Automatic analysis up to 10,000 relevant text files and 25 MiB of source
- Graphs up to 2,000 nodes and 5,000 edges
- Individual text files up to 2 MiB for viewing

Private repositories, GitHub Enterprise, accounts, cloud sync, full mobile authoring, code execution, and source-code mutation are not supported in 1.0.
