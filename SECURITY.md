# Security policy

## Supported versions

Security fixes are applied to the latest stable release and the active release-candidate branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email `mrwipbussiness@gmail.com` with:

- Affected version or commit
- Reproduction steps
- Expected impact
- Any suggested mitigation

Avoid including real credentials, private repository content, or personal data. Maintainers should acknowledge a report within three business days and provide a status update within seven business days.

## Security boundary

The hosted 1.0 profile supports public GitHub.com repositories only. It must reject private repositories and must not be configured with a shared GitHub token that can read private repositories. Blueprint drafts remain in the browser. When the user asks for a change in words and the built-in parser does not understand it, the instruction and a digest of the blueprint are sent to the explicitly selected AI provider; source code is not.
